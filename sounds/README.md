# Custom sound sets

Drop your own metronome sounds here. Each **folder** is one sound set, and the
folder name is the set's id.

## Layout

```
sounds/
├── woodblock/          # set id: "woodblock"
│   ├── tick.wav        # required — the regular beat
│   └── accent.wav      # optional — the downbeat (falls back to tick.wav)
└── my-drum/            # set id: "my-drum"
    └── tick.wav
```

A folder only shows up as an available set if it contains a **`tick.wav`**.
If there's no `accent.wav`, the downbeat reuses `tick.wav`.

## Rules for your WAV files

- **WAV (PCM)** — 16-bit (or 32-bit), mono or stereo both work. Any sample rate.
- **Keep them short** (a few tens to ~200 ms). These are clicks, not loops; the
  server plays a fresh copy on every beat, so very long files will overlap and
  sound muddy.
- **Level doesn't matter** — the server peak-normalizes every set on load
  (tick → 0.62, accent → 1.0), so a loud file and a quiet file both play at a
  consistent level, and the downbeat always reads clearly louder. You can use
  the UI/CLI **Volume slider** to change loudness across all sets.
- File names are case-sensitive on some systems — use exactly `tick.wav` and
  `accent.wav`.

## Adding / updating a set

1. Create `sounds/<your-set-name>/`.
2. Put `tick.wav` (and optionally `accent.wav`) inside it.
3. **Refresh the list** — in the web UI click "Refresh list", or run
   `node cli.js sounds`, or simply restart the server. The new set now appears
   in the "Sound set" dropdown / `node cli.js set <id>`.

## Built-in

The **`builtin`** set is always available. It's a click synthesized in
JavaScript (see `audio.js`) and needs no files — handy as a fallback.

## Try a different flavor

The bundled `woodblock` set is generated by `make_soundset.mjs`. You can
generate a new set into any folder with:

```
npm run sounds -- my-set
```

(Then feel free to overwrite the generated WAVs with your own.)
